Vertical Scroller - playtest build
==================================

Thanks for helping test!

1. Before unzipping: right-click the zip > Properties > tick "Unblock"
   (bottom of the General tab) > OK. Then extract it.
   This stops Windows from warning about the game.

   Already extracted, or no Unblock box? Double-click VerticalScroller.exe
   anyway.
   If Windows says "Windows protected your PC", click "More info" then
   "Run anyway". It warns because the game is new and isn't signed by a big
   publisher, not because anything is wrong.

(How to join a game and the controls are added here before the first release.)
