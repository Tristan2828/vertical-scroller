# Vertical Scroller (working title)

A pixel-art vertical scrolling space shoot'em up roguelite for online co-op (1–4 players), mostly in the style of Sky Force Reloaded: fly over enemy facilities, wreck them, and dodge readable bullet patterns. The gun fires by itself; you move, focus and use one special. Made in Godot 4. Windows only, keyboard, gamepad or mouse.

Early development: gray-box art (placeholder shapes), one stage played twice per run.

**Playtesting?** Grab the latest zip from [Releases](https://github.com/Tristan2828/vertical-scroller/releases/latest), unzip it, and run `VerticalScroller.exe`. The included `README.txt` explains joining, hosting and controls.
